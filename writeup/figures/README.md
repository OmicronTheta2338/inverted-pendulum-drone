# Figures

- `source/` holds editable SVGs, plotting notebooks/scripts, and non-final working exports.
- `final/` holds only publication-ready SVG/PDF/PNG assets referenced by the case study.

Name final figures by meaning rather than number, for example
`control-architecture.svg` and `latency-sweep-double.svg`. Figure numbers change during editing;
meaning should not.

Every quantitative plot should state its evidence class, configuration, run count, and units in
the figure or caption.
